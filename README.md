# 國小五六年級數學「檢測題與跨單元素養」四階梯學習共同體挑戰題庫

本專案依據教育部 108 課綱國民小學數學領域課程地圖，深度整合分析歷年縣市學生學力檢測題本（16份）與素養導向評量專書（4部），建立 35 個單元的橫向對照、難易度評量規準與學習共同體（探究與伸展跳躍）教學實踐指引。

---

## 🌟 核心成果亮點

1. **35 個核心單元完整對照表**：涵蓋 5上（10單元）、5下（10單元）、6上（9單元）、6下（6單元）。
2. **學習共同體四階梯挑戰架構（Four-Tier Challenge Architecture，全 140 題）**：
   - **🎯 Jump 1（概念探究題）**：橫跨 106～115 歷年檢測原題（100% 完整無改編），緊扣各單元核心認知衝突與概念瓶頸，破除迷思。
   - **🚀 Jump 2（延伸跳躍題）**：取材自教育部與縣市素養專書非選真題（100% 完整無改編），加深推理、反向逆推與數學表達。
   - **🌟 Jump 3（跨單元素養挑戰 A）**：概念縱向疊加，沉浸式生活實務建模長題幹，引導學童融會貫通先備核心概念。
   - **🔥 Jump 4（跨單元素養挑戰 B）**：橫向拓展深度素養長題幹，結合現代科技、工程、商業與公衛時事，激發高階數學建模思維。
3. **直擊全 140 題【學生常犯迷思概念剖析】**：
   - 深入診斷學童在直覺錯誤、位值守恆、公式誤用、單位量轉換與情境理解上的常見盲點，協助教師精準把脈。
4. **實戰型【學習共同體課堂引導建議】**：
   - 每題均量身打造「教師巡視觀察焦點」、「卡關關鍵提問設計」與「全班對話串聯策略」，促進同儕傾聽、協同探究與高階思辨。
5. **互動式網頁儀表板**：
   - 提供即時學期分類、難度過濾、關鍵字即時搜尋、一鍵「A⁺ 放大字體」與「大螢幕白板投影模式」。
   - 彈窗支援 Jump 1、Jump 2、Jump 3、Jump 4 四頁籤平滑切換，鍵盤 Tab 鍵可一鍵循環切換。
