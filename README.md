# 國小五六年級數學「檢測題與挑戰題」單元對照與學習共同體探究分析

本專案依據教育部 108 課綱國民小學數學領域課程地圖，深度整合分析歷年縣市學生學力檢測題本（16份）與素養導向評量專書（4部），建立 35 個單元的橫向對照、難易度評量規準與學習共同體（探究與伸展跳躍）教學實踐指引。

---

## 🌟 核心成果亮點

1. **35 個核心單元完整對照表**：涵蓋 5上（10單元）、5下（10單元）、6上（9單元）、6下（6單元）。
2. **題目屬性精準定位**：
   - **檢測題（Base 題）**：常模標準化診斷，定位學童起點行為與基礎概念精熟度。
   - **挑戰題（Jump 題）**：素養情境建模與建構反應題，直擊迷思概念，激發認知衝突。
3. **互動式網頁儀表板**：提供即時學期分類、難度過濾、關鍵字搜尋與一鍵列印友善功能。
4. **學習共同體（Learning Community）課堂指引**：規劃 Base $\to$ Jump 1 $\to$ Jump 2 課堂進階模組，並提供 4 人異質分組（ⒶⒷⒸⒹ）聆聽引導策略。
